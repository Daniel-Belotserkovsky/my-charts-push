קוד המנוי של המכשיר. העתק אותו והדבק באפליקציה, בלשונית ⚙️ הגדרות ← התראות פוש:
בשיאומי, כדי שההתראות לא "ייתקעו":
  1. הגדרות ← אפליקציות ← Chrome ← הפעלה אוטומטית (Autostart): להדליק
  2. שם ← חיסכון בסוללה ← ללא הגבלות
  3. שם ← התראות: לוודא שמותר, כולל "התראות צפות" ו"מסך נעילה"
  4. בתפריט של Chrome ← הוסף למסך הבית / התקן אפליקציה, כדי שיהיה אייקון של My Charts
